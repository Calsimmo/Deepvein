# Deepvein

An action-RPG overhaul mod for Minecraft 1.20.1 (Forge 47.x). Version 0.2.0.

## Download

The latest build is on the Releases page of this repository. Every push rebuilds it and starts a test server with the mod loaded.

## Installing

1. In CurseForge, create a Minecraft 1.20.1 profile with Forge 47.3.0 or newer.
2. Add Essential (Forge 1.20.1) to the profile.
3. Open the profile folder, then put the Deepvein `.jar` in `mods`.
4. Every friend who joins needs the same `.jar`.

## What is in it

| System | Details |
| --- | --- |
| Mana | Bar at the top right. Starts at 20 and regenerates. Mana Stars raise the cap to 200. |
| Magic | Ember Wand, Frost Staff, Storm Tome, Void Scepter. Right-click to cast. |
| Accessories | Five charms that work from the hotbar or off hand. |
| Health | Life Crystal Clusters underground. Each crystal adds a heart, up to 10. |
| Ores | Emberite, then Gloomsilver, then Aetherium. Each has a sword, pickaxe and armour set. |
| Blight | Purple patches on the surface that slowly spread. Purity Powder cleanses them. |
| Bosses | The Gloomwarden (Gloom Lantern, night only) and the Rift Tyrant (Rift Idol). |
| Town | The Town Bell calls a Tinkerer who trades for emeralds. |
| Storage | Vault Core with a paged screen, sort and quick-stack buttons. Each connected Vault Cell adds a page. Vault Remote opens it from afar. |
| Utility | Recall Mirror, Lodestone Charm (item magnet), Miner's Lens (night vision). |

## Progression

1. Mine Emberite with an iron pickaxe and smelt it.
2. Kill monsters at night under open sky for Stardust.
3. Craft a Gloom Lantern and beat the Gloomwarden for Warden Cores.
4. Combine 4 Raw Gloomsilver with 1 Warden Core for 4 Gloomsilver Ingots.
5. Collect Blight Spores from Blightgrass, craft a Rift Idol, and beat the Rift Tyrant.
6. Combine 4 Raw Aetherium with 1 Tyrant Heart for 4 Aetherium Ingots.

All recipes show up in the recipe book or a recipe viewer such as JEI.
